## Piece 1 — server hardening (audit P1, DECISIONS D2)

**Done.** The WebSocket takes an upgrade only from a page the game is served from, and a client
that stops reading is closed once 256 KiB wait unsent for it.

- **Origin check** (`apps/server/src/origin-guard.ts`, wired in `server.ts` through ws'
  `verifyClient`): the allow-list is the client's address on this machine (`localhost` and
  `127.0.0.1` on `CLIENT_PORT`), in `pnpm dev --lan` this machine's home-network addresses on that
  port (read from the network interfaces at start — the address `pnpm dev --lan` prints is among
  them, nothing is written down), in website mode `WEBSITE_ORIGIN` (a bare origin, checked by the
  new `envOrigin`; unset today). Exact match, no pattern. Unknown or missing `Origin`: 403 before
  it is a connection; each refused address is logged once (at most 1000 addresses, then silent),
  without the `Origin` value it sent.
- **Send bound** (`client-record.ts` `sendWithin`): before each send, a client holding more than
  256 KiB unsent (about 20 s of states at 32 ghosts on top of the system's buffers) is closed with
  1008 "send queue full" and sent nothing more; ws ends the socket after its close timeout. The
  page shows its existing text "The connection to the match server is gone. Reload the page to
  join again." (`apps/client/src/main.ts` 115, unchanged).
- **Who had to name an origin:** the probe's bots and spectator (`tools/probe`, a stand-in page
  `http://localhost`), the server tests' client (`test-client.ts`), and the e2e stacks, whose
  server now gets its client's port (`playwright.config.ts` `stack`; the hill and bomb servers had
  the default 5930 and would have refused their own clients).
- **Tests, each failing without the fix (sabotaged once each):** server "refuses an upgrade from a
  page the game is not served from with 403" and "… without an Origin with 403";
  `origin-guard.test.ts` (exact match only, logged once without the Origin, the log bounded);
  `client-record.test.ts` "closes a client whose unsent bytes passed the bound, and sends it
  nothing"; `env.test.ts` `envOrigin`. 3 of 3 sabotages caught.
- **Proof on `pnpm dev --lan`:** a fresh tab on `http://localhost:5930` at 1536 × 768 joined in
  447 ms; one on the home-network address `pnpm dev --lan` printed, at 390 × 844 with touch, in
  373 ms; a page served from `http://other.example` failed to open the socket; raw upgrades: 403
  with another `Origin`, 403 with none, 101 with the client's. The server log has exactly one line
  for the three refusals from this machine.
